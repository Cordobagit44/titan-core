# CORE-001 — Investigation Aggregate

## Objetivo

Como analista,

quiero poder crear una nueva investigación,

para comenzar un proceso de análisis de una empresa.

## Reglas

- Una investigación debe tener un título.
- Una investigación debe tener un propósito.
- Al crearse, su estado es `DRAFT`.
- Al crearse, debe emitirse el evento `InvestigationCreated`.
